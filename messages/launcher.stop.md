# summary

Stop Org Launcher's background server.

# description

Stops the server. If Org Launcher starts at login, it's stopped until your next login.

# examples

- Stop the server:

  <%= config.bin %> <%= command.id %>

# info.stopped

Stopped Org Launcher.

# info.stoppedUntilLogin

Stopped Org Launcher. It starts again at your next login. To stop that too, run sf launcher uninstall.

# info.notRunning

Org Launcher isn't running.
